SUPER YANA TESTER — ФАКТИЧЕСКИЕ ПОДКЛЮЧЕНИЯ
Текущая рабочая конфигурация: Pico SYT_fix119 + Nano Head fix6

RASPBERRY PI PICO

Кнопки TTP223:
UP   -> GP6
DOWN -> GP7
OK   -> GP22

Звук:
Пассивный бузер -> GP14

Подсветка TFT:
100% -> GP10
25%  -> GP11
50%  -> GP12
75%  -> GP13

Питание Arduino Nano:
Управление MOSFET -> GP15

UART Pico <-> Nano, 9600 бод:
Pico GP0 TX -> Nano D0 RX
Nano D1 TX -> делитель 1 кОм / 2 кОм -> Pico GP1 RX
GND Pico и GND Nano обязательно соединены

IR-приёмник:
OUT -> GP16

ADS1115:
SDA  -> GP8
SCL  -> GP9
VDD  -> 3.3V
GND  -> GND
ADDR -> GND
Адрес: 0x48

Каналы ADS1115:
A0 -> вольтметр через делитель 100 кОм / 10 кОм
A1 -> пробник / прозвонка
A2 -> свободен
A3 -> свободен

Аккумулятор:
Контроль напряжения -> GP29 / ADC3

TFT ST7735 160x128:
Пины TFT задаются в библиотеке TFT_eSPI / User_Setup.h
Фактическое рабочее распределение:
CS   -> GP17
SCLK -> GP18
MOSI -> GP19
DC   -> GP20
RST  -> GP21

ARDUINO NANO — ИЗМЕРИТЕЛЬНАЯ ГОЛОВКА

Измерительные точки:
TP1 -> A0
TP2 -> A1
TP3 -> A2

Резисторная матрица тестера:
D8-D13 -> цепи 680 Ом / 470 кОм

Кнопка Nano на A3 отключена.
Тест запускается только командой @TEST от Pico.

Питание Nano:
От повышающего преобразователя MT3608, выход 5.00 В

Важно:
- Nano остаётся включённой при обычном автосне Pico.
- При критическом разряде аккумулятора Pico отключает Nano.
- GP0 и GP1 не использовать ни для чего кроме UART.
- GP15 не использовать для подсветки: это управление питанием Nano.
